📡 The Big Signal: Gemini 4 Hydrogen makes fast cheap

In short: Google released a fast, low-cost coding model that matches its flagship on a key index.

On Thursday (12 November) Google launched Gemini 4 Hydrogen, built for everyday coding and agent work. It's live in the Gemini API, AI Studio and Android Studio, with four thinking levels and a 1-million-token context window.

Hydrogen scores 51 on the Artificial Analysis Intelligence Index at its default setting, edging Gemini 4 Argon's 50. Pricing is flat across the whole window at $1.50 per million input tokens and $7.50 per million output tokens. Google's new Orchestrator in Antigravity swaps between Carbon and Hydrogen mid-session; on Terminal-Bench 4.0 it neared Carbon's success rate using 24% less quota.

Why this matters: most coding work is routine, and a model this cheap that scores like a flagship changes what an agent run costs.

Sources: Google · Google for developers

⚡ Quick Hits

In short: Google added two specialised TPUs, one for confidential AI and one for huge context windows.

Google's TPU family gets 8tx and 8i Max. TPU 8tx keeps data and model weights protected even while in use, so regulated firms can fine-tune and serve on one system. TPU 8i Max packs two TPU 8i chips into one package for double the compute and HBM bandwidth; no pricing or dates yet. Google · TechCrunch

Why this matters: banks and governments wary of shared AI chips now have a purpose-built option.

In short: AMD added a new Instinct GPU and claimed a win over NVIDIA's newest chips.

AMD launches MI450X and swings at Vera Rubin. MI450X brings 288 GB of HBM4 per GPU with the same compute as MI455X. AMD also says MI455X on Helios hit 21,333 tokens per second per GPU on DeepSeek-R1, up to 30% above NVIDIA Vera Rubin's latest published MLPerf offline result. AMD

Why this matters: a credible second supplier keeps GPU prices honest, though vendor benchmarks deserve independent checks.

In short: Cerebras posted record sales on demand for very fast AI responses.

Cerebras hits record revenue. Q3 GAAP revenue hit $210.8 million, with cloud revenue up 265% year on year and guidance raised. Oracle will offer Cerebras inference on OCI in 2027. Cerebras

Why this matters: buyers are paying for speed, not just training power, which means snappier AI apps.

In short: Copilot in Visual Studio now runs on the same engine as GitHub's other Copilot tools.

Visual Studio 18.12 gives Copilot a new engine. Copilot Chat now runs on the Copilot SDK built by GitHub, the engine behind Copilot CLI and VS Code, on by default. Across 100-plus test tasks it beat the old version with every model tried, solving up to 21 more. Microsoft

Why this matters: if you code in Visual Studio, one update gets you a smarter assistant without changing models or plans.

🛠️ Tool of the Week: Modern Web Guidance 1.0

In short: a free skill pack that teaches your coding agent today's web best practices.

Chrome's Modern Web Guidance hit 1.0 on Tuesday. It plugs expert-reviewed web guidance and browser compatibility data into your coding agent, covering hundreds of known AI knowledge gaps. New in 1.0: a workflow that scans an existing codebase for safe upgrades, plus a public eval dashboard. Firefox and Edge have joined. Install from your project folder with npx modern-web-guidance@latest install.

Why this matters: AI-written web code often "works" but is slow or inaccessible; this nudges your agent towards expert habits.

💡 One Takeaway

Route the routine work to the fast model. Hydrogen and Orchestrator point the same way: most agent steps are routine and don't need your priciest model. Try a two-tier setup this week — a frontier model to plan and review, a fast one to write code and run tests — and compare cost and pass rate on a few tasks from your own backlog.
