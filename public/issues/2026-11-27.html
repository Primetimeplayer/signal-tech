📡 The Big Signal: Claude Ship lets AI approve your pull requests

In short: Anthropic launched AI agents that review, fix and, if your rules allow, approve code changes on GitHub.

On Monday (23 November) Anthropic launched Claude Ship in beta. It bundles three agents. Code Review, already generally available, checks a pull request at Quick, Standard or Deep level. PR Steward jumps in on failing CI checks, merge conflicts and review feedback, and explains every push and how to undo it, but won't approve or merge. Claude Approvals then applies an approval policy your team writes as a file in the repo, a bit like a smarter CODEOWNERS.

Developers can run /ship in Claude Code to push, open, review and fix a PR. Anthropic recommends starting Approvals in observe-only mode. It's on Claude Team and Enterprise plans for GitHub repos, billed on tokens.

Why this matters: code is being written faster than people can review it, and this hands part of the sign-off to AI, under rules you set.

Sources: Anthropic · TechCrunch

⚡ Quick Hits

In short: the company behind the Devin coding agent released a much stronger model.

Cognition releases SWE-2.1. Trained with reinforcement learning on Moonshot's open Kimi K3, it scores 41.3 on FrontierCode 2.0 (up from 24.1) and 50.0 on Terminal-Bench 4.1 (up from 24.2), by Cognition's own tests. Cognition says it's also much better at finding and exploiting security flaws, so it shipped with safeguards. Cognition

Why this matters: open models are now a serious base for top coding agents, though these are the maker's own numbers.

In short: a Chinese AI lab built a model that runs its layers twice to reason more deeply.

Z.ai launches GLM-5.4. It reuses 28 layers of its 750B-scale base for two passes, which Z.ai says puts it on par with 2–3 trillion-parameter models, with a 1-million-token context. It's in Z.ai Chat and the GLM Coding Plan now, with the API "coming soon", and Z.ai admits it can get stuck in "marathon thinking" loops. Z.ai

Why this matters: smarter design, not just bigger models, could make capable AI cheaper to run.

In short: TSMC has filed plans for a huge new chip factory in Texas.

TSMC proposes a $22.6bn Texas fab. Filings show a 3,200-acre site in Brazos County making 2nm chips for AI, high-performance computing and phones, with at least 2,099 jobs by 2032. TSMC is seeking a $354m tax break and is still weighing Arizona instead. Manufacturing Dive

Why this matters: more of the world's most advanced chips could be made in the US, which affects supply and prices.

In short: a new US rule is pushing sellers to offload top NVIDIA chips meant for China-linked customers.

NVIDIA GPUs flood the resale market. A US rule in force since 19 November stops Chinese firms renting advanced NVIDIA chips in overseas data centres. Sources told CNBC that sellers are now floating deals for thousands of B300 GPUs. CNBC

Why this matters: export rules now shape who can rent AI compute, not just who can buy it.

🛠️ Tool of the Week: Vite 8.4

In short: a free update to the popular web build tool that makes its dev server harder to attack.

Vite 8.4 landed on Thursday with a stricter, allow-list file check. Set server.fs.strict: 'extended' with server.fs.allow: [] and the dev server only serves files your entry point actually references. It also re-fetches CSS when a failed dynamic import is retried, supports subpath imports in CSS url(), and blocks accidental duplicate dev servers.

Why this matters: a dev server left reachable on a network can leak files, and this closes most of that gap.

💡 One Takeaway

Let AI watch before it approves. If you hand reviews or merges to an agent, start it in observe-only mode on one repo. Compare its calls with your reviewers' for two weeks, then let it approve only the routine changes it got right.
