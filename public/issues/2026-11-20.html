📡 The Big Signal: GPT-6.2 is cheaper, sharper… and divisive

In short: OpenAI released two new models, a top-end one and an everyday one, with lower costs per task.

On Tuesday (17 November) OpenAI launched GPT-6.2 Astra, its new frontier model, and GPT-6.2 Sol for everyday work. Both are in ChatGPT, Codex and the API.

OpenAI says Astra scores 5.2 points higher than GPT-6 Astra on Agents' Last Exam at less than a third of the cost. API prices drop 20% to $8 per million input tokens and $40 per million output, with cached input 60% cheaper at $0.40. Sol keeps its $2/$10 pricing, and on Cognition's FrontierCode 2.0 it lands within 0.5 points of Astra at about a fifth of the cost.

The early reviews were rough, though. VentureBeat rounded up power users calling it "essentially unusable", while Ethan Mollick found Astra "very uneven & weird" and harder to steer than rivals.

Why this matters: benchmarks and real work don't always agree, so try a new model on your own tasks before making it your default.

Sources: OpenAI · ChatGPT Learn · VentureBeat

⚡ Quick Hits

In short: Google released a new mid-priced model aimed at coding and agent work.

Google ships Gemini 4 Neon. Google says Neon ranks #3 overall on the Artificial Analysis Intelligence Index with a score of 61, at $3 per million input tokens and $15 per million output, with a 1-million-token window. It's in the Gemini API and Antigravity, and went GA in GitHub Copilot a day later. Google · GitHub

Why this matters: you get close to top-tier quality without paying top-tier prices.

In short: NVIDIA reported another record quarter as its newest AI system started shipping.

NVIDIA books $115.8bn in a quarter. Revenue rose 103% year on year, with $107.6bn from data centres, and Vera Rubin NVL72 has started shipping. NVIDIA guides $130bn for next quarter and assumes no data-centre compute revenue from China. NVIDIA

Why this matters: demand for AI hardware still isn't slowing, which shapes cloud GPU prices and availability for everyone.

In short: NVIDIA announced a new GPU built for scientific simulation rather than chatbots.

NVIDIA unveils Rubin HPC. Announced at SC26, it packs more than 50,000 CUDA cores on one GPU, plus sparse-data acceleration and seventh-generation NVLink. It targets the simulations science and engineering agents rely on, and is due in 2028. NVIDIA

Why this matters: AI agents in labs still need classic number-crunching, and NVIDIA is building chips for that too.

In short: Microsoft released its own budget coding models inside GitHub Copilot.

Microsoft launches MAI Code 2 and Code 2 Flash. Microsoft claims MAI Code 2 delivers 98% of GPT-6.1 Sol's performance at 40% of the cost across four everyday coding benchmarks. Both are in GitHub Copilot now, with Flash in limited preview in Foundry. Microsoft AI

Why this matters: more cheap coding models means more choice, but these are Microsoft's own numbers, so check them yourself.

🛠️ Tool of the Week: VS Code 1.147

In short: a free VS Code update that lets a "router" pick the right AI model for each task.

VS Code 1.147 landed on Wednesday with experimental model routers: a short YAML file that says which model handles which kind of request, such as a big model for multi-step code changes and a fast one for quick questions. Turn on chat.copilot.modelRouter.enabled, then type /model-router in chat to write one. It also adds Send Later, so you can schedule an agent request for the morning.

Why this matters: you stop paying flagship prices for small jobs, without switching models by hand.

💡 One Takeaway

Run your own eval before you switch. This week brought three new coding models and one very split verdict. Before changing your default, pick five real tasks from your backlog, run them on your current model and one newcomer, and compare pass rate, cost and how often you had to step in.
