This week the world's biggest code platform rebuilt itself around AI agents, two new models landed, and AI chip money got even bigger. Five minutes, tops. Let's go.

📡 The Big Signal: GitHub rebuilds itself around AI agents

In short: GitHub launched a new Copilot app where AI agents do the work across your projects and you approve the results.

At GitHub Universe on Wednesday (28 October), GitHub said its goal is now "completed software work", not more code. The centrepiece is the GitHub Copilot app: you give it a goal and some context, it runs as many agents as the job needs across several repositories, and it brings back pull requests for you to review.

Alongside it came Copilot Fusion, which picks the right model (or mix of models) for each task, a deeper "Max" level of Copilot code review, and sessions you can start on your phone and pick up in VS Code. The commercial twist: GitHub Enterprise customers now get every Copilot feature without a separate subscription, paying for the AI credits they use.

Why this matters: writing code is becoming the cheap part; the skill that counts is deciding what to build and checking what the agents hand back.

Sources: GitHub blog · GitHub Changelog

⚡ Quick Hits

In short: OpenAI released a fast, cheaper model that's good at using a computer for you.

OpenAI's GPT-6.1 Terra halves the price. Terra is built for everyday work such as understanding images, filling in forms and coding, and its API price is 50% lower than GPT-5.6 Terra's, at $1 per million input tokens and $5 per million output. OpenAI says it more than doubles its predecessor's score on the Terminal-Bench 4.0 coding test and makes far fewer factual errors. OpenAI

Why this matters: jobs like typing invoice details into accounting software are getting cheap enough to hand to AI at scale.

In short: Google's newest top model is built to find and fix security holes.

Google's Gemini 4 Carbon puts security first. Just two weeks after Argon, Google announced Carbon, which tops the Artificial Analysis Intelligence Index and scores 88.2% on SEC-bench Pro for finding real software vulnerabilities. It's going to a small group of cyber defenders first, with wider access promised "as soon as possible" at $2/$10 per million tokens. Google

Why this matters: AI that can find security holes this well is useful to attackers too, which is why Google is giving it to defenders first.

In short: banks are lending $63 billion so Anthropic can rent Broadcom's AI chips.

A $63B loan to rent AI chips. Bank of America, Blackstone, Citi and Morgan Stanley are funding a new company that will buy Broadcom's AI accelerators and networking gear and lease them to Anthropic, with deliveries from 2027. Broadcom is backing part of the financing itself. Broadcom

Why this matters: AI chips are now financed like aircraft or buildings, which shows how much capital the AI build-out is soaking up.

In short: Europe is getting the world's first large-scale factory for a more efficient kind of power chip.

Infineon bets €1.1B on gallium nitride in Austria. Infineon will turn existing cleanrooms in Villach into the world's first high-volume plant for gallium nitride (GaN) power chips on 300mm wafers, with production due by the end of 2027. Bigger wafers yield 2.3 times as many chips each, and the EU has approved €319 million in state aid. Infineon

Why this matters: GaN chips waste less electricity as heat, and AI data centres badly need to save power.

🛠️ Tool of the Week: Local Code

In short: a free, open-source AI assistant for the Mac that runs entirely on your own computer.

Draw Things has released Local Code, an AI agent that writes and reviews code, edits spreadsheets and slides, makes images and can work with your Mac's Mail, Notes and Calendar, all without sign-ins, API keys or sending your files to the cloud. Smaller models run on Macs with 16GB of memory; the biggest wants 64GB or more. The whole app is open source (GPL-3.0) on GitHub.

Why this matters: if privacy rules stop you pasting work files into ChatGPT, a capable assistant that never leaves your machine is a real alternative.

💡 One Takeaway

Get good at reviewing, not just prompting. GitHub, OpenAI and Google all pitched the same future this week: agents do the work, and you check it. Start practising now. When AI hands you code, a draft or a spreadsheet, read it as if a new colleague wrote it: test the claims, run the code, and ask what's missing. That habit will matter more than any single tool.
